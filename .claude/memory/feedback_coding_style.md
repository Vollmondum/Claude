name: Coding style preferences
description: How to use bash commands and when to write code comments
type: feedback
---

Use bash/shell commands sparingly — only run them when truly necessary.

Only add comments to complex code. Do not comment simple, self-explanatory code.

**Why:** User prefers minimal noise in both terminal output and source files.

**How to apply:** Before running a command, ask whether it's strictly needed. When writing code, default to no comments; add one only when the logic is non-obvious or has a hidden constraint.
